## DevOps Fundamentals

A collection of notes and practice examples covering foundational DevOps concepts.

### Topics Covered

- **Linux** — commands, file management, permissions, and the Vi editor
- **Bash Scripting** — variables, inputs, conditionals, arithmetic, and command-line arguments
- **YAML** — syntax, data types, anchors, and styles

This repository serves as a quick reference for Linux, shell scripting, and YAML fundamentals.
